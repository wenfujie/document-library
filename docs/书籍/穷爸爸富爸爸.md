# 穷爸爸富爸爸

这是一本观念重构的书，而不是实操。

> 全书六课：富人不为钱工作 · 为什么要教授财务知识 · 关注自己的事业 · 税收的历史和公司的力量 · 富人的投资 · 不要为金钱而工作

## 第一章：富人不为钱工作

**富爸爸教育我——**

**错误的认知【老鼠赛跑】**：普通人怕火灾、怕生病、怕丢失工作、怕付不起房贷车贷，所以会追求一份稳定的工作。他们的生活模式是：起床、上班、付账单，第二天再起床、上班、付账单，如此循环。如果钱不够用，他们会要求涨薪或者跳槽换一份工作，但这解决不了根因——他们始终在为了钱而工作。为此，他们失去了学习某种专业技能的机会，也失去了创业的可能，只能拼命为钱工作，成为金钱的奴隶。

**正确的认知**：让钱为我们工作。

## 第二章：识别资产和负债

核心规则：搞清楚什么是资产、什么是负债，买入资产，减少负债和支出。

- **资产**：可以把钱放进口袋的东西
- **负债**：从口袋里拿钱出来的东西

那么，应该获得什么样的资产呢？真正的资产可以分为下列几类：

1. 不需要我到场就可以正常运作的业务。我拥有它们，但由别人经营和管理——如果我必须在那儿工作，那它就不是我的事业，而是我的职业了
2. 股票
3. 债券
4. 共同基金
5. 产生收入的房地产
6. 票据（借据）
7. 专利权，如音乐、手稿、专利
8. 任何其他有价值、可产生收入或可能增值、并且有很好流通市场的东西

## 第三章：关注自己的事业

一生在为别人工作的人，一旦停止工作，往往变得一无所有。

## 第四章：税收和公司

**普通人的纳税**：越努力工作，工资越高，纳税就越多。

**如何利用公司避税？**

企业赚钱后，先扣掉花出去的钱，再对剩下的钱纳税。富人利用这个规则，买车、车子的保险和修理费用、健身房会员费、大部分餐饮费等等，都可在税前支付。

**富人避税的手段**

1. 借助公司避税：企业所得税低于个人所得税，公司的某些支出可在税前获得减免
2. 雇佣律师和会计
3. 说服政客改变法律，或钻法律的漏洞
4. 了解并利用合法的避税手段：如为购买更贵的房地产而卖出现有房地产时，所获得的资本利得可推迟纳税

**怎么做？**

1. 了解法律：利用法律赋予的权利去实现自己的事业

**财商的组成**

1. 财务知识：帮助你辨别业务的优劣，看懂财报
2. 投资
3. 了解市场
4. 法律：帮助你有效运营一个进入会计、投资和市场领域的企业，实现爆炸性增长

## 第五章：不要为了钱而工作

1. 强调不断学习的重要性
2. 强调学习团队管理
3. 推崇学得广而不是深：比如学习一个公司的各个部门是如何运作，而不是精通某个部门的工作内容
4. 破产最好在 30 岁之前

## 第六章：开始行动

1. 列出致富的原因：想要的 N 条、不想要的 X 条
   - 例如：想要买大房子、豪车；不想一直上班
2. 每天做出选择：利用好时间，做金钱投资、学习
3. 慎重选择朋友：从富人朋友身上学习财商知识，从穷人朋友身上了解哪些事情不可做
4. 掌握一种赚钱的模式，然后再学习一种新的模式，如此循环
5. 自律：现金流管理、时间管理、人事管理
6. 首先支付自己：就算负债，也不用动用自己的储蓄或股票来还钱（有点偏激了），而是用负债激励自己开辟赚钱的途径
7. 给你的经纪人优厚的报酬
8. 对英雄的崇拜，并学习他们的优点
9. 先予后取

## 名句

1. 你学习什么，就会成为什么样的人：学烹饪就会成为厨师，学教学就会成为老师，学财商就会成为商人
2. 工作的意义就是「比破产好一点」
