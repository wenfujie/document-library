# 《小狗钱钱》读书笔记

## 确认3个想变富有的愿望

按书中方法，写满 10 个后再挑出最重要的 3 个。

## 为实现愿望要努力做到三件事

**一 · 愿望影集**

制作愿望影集。收集一些与自己的愿望有关的照片，把它们贴在影集里。我们要通过图片来思考。

**二 · 视觉化**

每天看几遍像册，然后想像着，你已达成愿望后自豪的神情。

**三 · 梦想储蓄罐**

为挑选好的3个愿望准备3个梦想储蓄罐。

## 培养自信：成功日记

自信是财富的来源，所以需要培养出我们的自信。

怎么做？每天都记录成功日记，它可以是每天完成的一些小事，只要能为我们带来一些成就感都可以记录。

顺风顺水时很容易坚持，但逆境才是考验你坚定的定律的时候。

## 赚钱理论

- 金鹅定律：本金是鹅，利息是蛋，不准杀鹅，蛋是源源不断的收入。
- 资产分配（参考即可）：收入的 50% 养鹅、40% 给梦想、10% 日常
- 赚钱定位：聚焦在能做到的、拥有的、知道的事情上
- 利用自己热爱的事情来赚钱：你最好想清楚，你喜欢做什么，然后再考虑怎么用它来挣钱。
- 幸运其实只是充分准备加上努力工作的结果。
- 不要为失去的东西而忧伤，而要对拥有它的时光心存感激。
